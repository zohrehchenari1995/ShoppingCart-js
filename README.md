# 🛒 Shopping Cart Application

A fully responsive and interactive Shopping Cart Application built with **HTML, CSS, and Vanilla JavaScript**.  
This project demonstrates dynamic DOM manipulation, clean UI structure, and a complete cart management system without using any frameworks.

---

## 🔗 Live Demo  
👉 **https://zohrehchenari1995.github.io/ShoppingCart-js/**

---

## 📌 Project Overview

This application allows users to:

- Add unlimited products to the cart  
- Increase or decrease product quantities dynamically  
- Remove individual items  
- Clear the entire cart  
- Automatically calculate the total price based on quantity  
- View the cart inside a modal with smooth animations  
- Enjoy a fully responsive UI across mobile, tablet, and desktop  

The cart system is fully implemented in JavaScript, using event listeners, DOM updates, and local state handling.

---

## ⭐ Key Features

### ✔ Add to Cart  
Each product includes an “Add to Cart” button that instantly updates the cart UI.

### ✔ Quantity Control  
Users can increase or decrease the quantity of each product directly inside the cart modal.

### ✔ Auto Price Calculation  
The total price updates automatically whenever the quantity changes.

### ✔ Remove Items  
Each cart item includes a delete icon for quick removal.

### ✔ Clear Cart  
A dedicated button clears the entire cart with one click.

### ✔ Modal Cart  
The cart appears as a centered modal overlay with smooth transitions and scrollable content.

### ✔ Fully Responsive  
Designed with CSS Grid, Flexbox, and media queries to ensure perfect display on all screen sizes.

---

## 🛠️ Tech Stack

- **HTML5**  
- **CSS3** (Flexbox, Grid, Responsive Design)  
- **JavaScript** (DOM Manipulation, Events, State Management)

---

## 🚀 How to Use

1. Browse the product list  
2. Click **Add to Cart** on any item  
3. Open the cart using the cart icon  
4. Adjust quantities or remove items  
5. View the updated total price instantly
